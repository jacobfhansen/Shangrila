# Shangrila

A Godot 4 recreation of *Shangrila*, an unfinished Macintosh adventure game written in Pascal in 1997.
The game lives in [`Shangrila-godot/`](Shangrila-godot); see its [README](Shangrila-godot/README.md).

Plans and ideas are collected in [IDEAS.md](IDEAS.md).
